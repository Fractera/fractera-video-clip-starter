# fractera-lego-motion — заглушка

Навык стиля проекта: как выглядят и двигаются сцены FRACTERA (фигурки и кирпичи-элементы, камера, свет, типографика, выноски, ритм под песню). Подключается на шаге 1 навыка reference-to-clip как набор правил «стиль проекта».

Статус: версия 2 предложена в чате карточкой навыка, но ещё не сохранена, поэтому её текста здесь нет.

Как заменить заглушку:
1. Роман сохраняет карточку fractera-lego-motion в чате.
2. Сохранённая копия появляется в `/root/.claude/skills/synced/<org>_<account>/fractera-lego-motion/SKILL.md` (облачная сессия Claude).
3. Скопировать её сюда как `SKILL.md`, этот README удалить, отметить в `JOURNAL.md`.

Пока навыка нет, опора — то, что уже воплощено и описано:
- `engine/` — движок и пробный ролик test 01 (сцены S01–S03): палитра, шрифты, кривые движения, выноски, терминал, подпись по словам;
- копии документов в `docs/`: `3d-video-spec-part1-rev20.md` (спецификация 3D-ролика, кадры S01–S15, по ней сделан test 01) и `library-rev13.md` (грамматика стиля образца, каталог блоков);
- `.claude/skills/vizavi-motion/` — качество движения (общие правила, не стиль FRACTERA).
