# Fractera Lego Motion

Один визуальный язык, одна библиотека блоков и один проверенный конвейер для всех роликов Fractera. Мир: AI-агент (коралловая фигурка Claude с лендингов) несёт на спине фичи-кирпичики; маленькие сборки стоят, большие без архитектуры падают. Архитектура в этом мире всегда синяя (#2563EB). Формат серии — клип на песню: каждая строка текста — один визуальный блок.

Приоритет: явный бриф пользователя > этот навык > дефолты. Не выдумывай реальные свойства продукта, цены и метрики; внутримировые счётчики — художественные.

Опорные материалы:

- ТЗ Part 1 «STACK OVERFLOW»: https://claude.ai/artifact/FpjVNv8SMq5C1taKNDEcNs

- Референс-клип (5:05) сделан по его титрам связкой «анимация Claude Opus 5.5 + песня Suno v6» — именно наш конвейер. Берём из него приёмы, не кадры и не текст песни.

## Ядро: три механики (из vizavi_motion)

1. **Качество по умолчанию.** Анимируй стилизованные объёмные формы в трёхмерном пространстве. Используй перспективу, мягкое освещение и осмысленное движение камеры. Камера движется, пока идёт действие; планы различаются масштабом и параллаксом; у объектов есть вес, инерция, контакт и тень; типографика участвует в действии; музыка и SFX по умолчанию.
2. **Режиссура до реализации.** Нить → песня → монтажный лист (строка → блок). Для каждой сцены 3–5 коротких вариантов, выбери сильнейший. Главный риск проверь ключевыми кадрами до полного рендера.
3. **Итерация после первой сборки.** Первый рендер — черновик: разбери кадры, стыки, синхрон с дорожкой, исправь, перепроверь итоговый MP4. Статусы честно: реализовано / запущено / видно в кадрах / проверено в движении / прослушано.

## 2. Типографика клипа

1. **Строка песни** — жирный гротеск (Inter 800–900), влево, 1–4 строки. Слова появляются ровно на слог, недопетое слово — по буквам, ключевое — акцентным цветом режима.
2. **Ироничные слова** — dot-matrix контур, leet-код, зачёркивание с рукописной правкой, сжатие рамкой трансформации, текст по кривой графика или по окружности, слова на цветных плашках-токенах, слово из слетающихся частиц.
3. **Глоссы** — мелкий serif-курсив (подписи под буквами, словарные статьи, ленты, латинские названия гравюр).
4. **Хром** — моно капсом 7–9 px в углах: хлебные крошки части песни, живые счётчики, номер слайда, полоса прогресса.
5. **Рукопись** — красный маркер: пометки в скобках, стрелки, обведения; капитель-рукопись на чеках и записках.
6. **Штампы** — резиновая печать (APPROVED, FIXED!, GRANTED, BLAMELESS, серии дублей): удар с поворотом и тряской.

## 3. Библиотека блоков

Блок = переиспользуемый компонент с параметрами (текст, цифры, персонажи, режим), как блоки в проекте Fractera. Длина — 1–4 такта (2–8 с). Куплеты придумывают новую метафору на каждую строку; припев повторяет те же блоки, но с маленькой переменой, которая двигает историю (в референсе: люди в совете директоров становятся ботами, чёрный ящик трескается и дымит). Клип замыкается в кольцо: финал возвращает первый блок с новой панчлайн-репликой.

Семейства (полный каталог с временем и адаптацией — в документе библиотеки):
- **Чат и UI:** сообщение в чате, запрос доступа с тумблерами, ответ бота Done!✓, инцидент-чат с петлёй одинаковых ответов, статус-страница (красное → зелёное), форма с автодополнением, PR-карточка с merge.
- **Код:** логотип из строк кода, стена кода со счётчиком, код-лирика leet, системный промпт, код с сигнальными лентами, DROP TABLE.
- **Стейдж:** кейноут с залом, таблички в руках, пьедестал с прожектором, полицейский опознавательный ряд.
- **Слайды и данные:** список приоритетов, оргструктура, Гант, текст по графику, столбцы-сравнение, биржевой график, метрики.
- **Предметы-метафоры:** чёрный ящик кода со сносками, CRT-монитор, корабль с контейнерами-буквами, серверная стойка, часы (настенные, цифровые, секундомер), цилиндр базы данных, чек и банковский чек, бейдж на ленте, каталожная карточка, гравюра (облако, жук), пластинка на проигрывателе, доска улик с красной нитью, бумажные человечки, которых режут.
- **Переходы:** точка света, сканлайн, zoom-through, разрыв бумаги, треснувшее стекло, глитч/скрамбл.
- **Наши 3D-блоки:** «рождение агента» (сборка со сносками → материализация → первый кирпичик), башня фич, падение, поле агентов.

**LGTM → FRACTERA.** FRACTERA ставим там, где буквы — визуальный герой (из кода, плитки-печати, контейнеры, стойка, таблички). Восемь букв вместо четырёх: мельче и чаще или две строки FRAC / TERA. Компания-антигерой из сатиры — вымышленная и нейтральная, никогда не FRACTERA: FRACTERA — решение.

## 4. Песня и Suno (конвейер «сначала песня»)

1. Пользователь рассказывает историю; читаем репозитории Fractera и формулируем ценность архитектуры.
2. Пишем текст и бриф трека: жанр, темп (референс ≈ 118 BPM, такт ≈ 2 с), структура с тегами [Intro] [Verse] [Chorus] [Bridge] [Outro], хук, язык. Строки короткие: одна строка = один блок на 1–4 такта; в каждой строке одно ударное слово под акцент. Бэк-вокал и эхо обычно пишут в круглых скобках.
3. Трек с вокалом делается в Suno. У Suno есть официальный MCP-сервер (Suno MCP Beta, анонс 28.10.2026): адрес `https://api.suno.com/mcp`, без API-ключа, вход аккаунтом Suno; ранний доступ через форму заявки; в Claude подключается как кастомный коннектор (нужен платный план); тратит кредиты Suno. Умеет: песня в диалоге, голосовая заметка → трек, ремикс, сохранённый Suno Voice. Если коннектора нет — пользователь генерирует сам и присылает файл. Вокал сами не синтезируем; инструментал можно кодом.
4. Разметка трека: биты и такты (spectral flux + автокорреляция на numpy), секции, начала фраз; время слов — по таймкодам текста из сервиса или ручной разметке.
5. Монтажный лист: время · блок · текст · акцент · переход; смена блока на сильную долю, слово на слог. Пользователь утверждает.
6. Рендер по сценам (раздел 11), сборка под дорожку, проверка.

## 5. Звуковой бренд: распевка FRACTERA

Авторская запись (сохранять дословно):

```text
FRA..FRA…FRA…FRACTERA…A…A…AAaaaA…FRA…FRA…FRACTERA..UUuUu…!
```

Расшифровка: три коротких ударных «FRA» с разгоном → полное «FRAC-TE-RA» → распев на «А» вверх-вниз (тихо–громко–тихо) → два «FRA» → снова «FRAC-TE-RA» → финальный вокализ «Ууу…!» с восклицанием. Роль: хук припева, джингл интро/аутро, музыкальный логотип.

Запись для текста в Suno (стартовая, подбирать на слух):

```text
[Hook]
Fra! Fra! Fra! FRAC-TE-RA!
(A-a-a-aaa-a)
Fra! Fra! FRAC-TE-RA!
(Uu-uu-uuu!)
```

Лучший путь передать мелодию: пользователь напевает распевку голосовой заметкой, Suno превращает её в трек.

Визуальная синхронизация: каждое «FRA» — удар плитки F, R, A; «-CTERA» — остальные буквы одним росчерком; распев «А» — буквы идут волной и светятся; «Ууу…!» — переход «точка света» (синяя точка архитектуры).

Флажок `I'M OK` в правой руке никогда не признаёт проблему (`I'M OK` → `I'M OK?` → снова `I'M OK` рядом с упавшим). Голос — сервописки. Никогда: шипы, одежда, логотипы, рот, лишние конечности, смена пропорций.

## 8. HUD, камера, физика

- **HUD** (DOM поверх WebGL на том же t): стеклянные панели rgba(14,19,32,.58) + blur 24 px + рамка 1 px + радиус 16; сноски как на лендинге (точка → линия 1.8 px #E2E8F0 → печатающаяся подпись, буквы алфавита по порядку, стороны чередуются); терминал с промптом, skeleton-шиммером и спиннером; титры — слова падают как кирпичики; маркер части `● 01 · STACK IT`. Плотность: 1–2 панели в спокойной фазе, без лимита в хаосе, ноль в тишине; не закрывать лицо и летящий объект. Экранный текст по-английски, коротко, оригинально; агента не обвиняем.
- **Камера:** fov ~30°, уровень глаз агента, базовый вид три четверти (не мёртвый фронт); движение мотивировано (дуга, облёт, подъём навстречу объекту, наезд на эмоцию, кран на раскрытие). Ноги агента выше строки титра (≤ ~860 px из 1080), агент в центральной зоне 9:16.
- **Физика:** игрушечный масштаб, сжатие растёт с массой (4% → 12%); башня — цепь звеньев с запаздыванием 3–5 кадров (S-волна); обрушение по слабому звену, speed ramp 100% → 20% → 100%; всё детерминировано (seeded RNG, bake симуляций).

## 9. Мир 3D-сцены и свет

Navy-пол со сеткой (шаг 0.4, гаснет в глубину), дымка, пылинки. Фирменный переход «чертёж → игрушка»: сначала плоский вид (emissive-карта, штрихованная тень), за ~0.6 с включается свет, тени, рельеф штриховки, тёплое пятно на полу. Цветовой сценарий: чертёж → тёплый ключ (легко) → нейтральный (вес) → холодный циан + красный пульс (хаос) → лунный (после) → синий #2563EB по сетке (архитектура). Пост: bloom только на HDR-бликах (порог ≥ 1.0, сила ≤ 0.22), виньетка, зерно ~7%.

## 10. Звуковой дизайн без песни

Если трека ещё нет: numpy-синтез (тоны с огибающей, FFT-полосовой шум, реверб свёрткой), SFX на те же таймкоды, что и события сцены (свисты, печать, клики с понижением высоты по весу, сервописки, «успех»), блипы панелей с панорамой на их сторону. Микс: ffmpeg `loudnorm=I=-14:TP=-1.5`, AAC 192k. Не прослушано человеком — так и сказать.

## 11. Конвейер рендера (проверено 2026-11-07)

Стек: Three.js (npm `three`), шрифты `@fontsource/inter` и `@fontsource/jetbrains-mono`, Chromium через Playwright (`/opt/npm-tools/node_modules/playwright/index.mjs`, браузеры `/opt/pw-browsers`), WebGL через SwiftShader, ffmpeg. Скорость ≈ 0.9–1.6 с/кадр 1080p на 2 ядрах → рендер кусками ≤ 8 с видео на команду или фоном в пределах хода; файл на сцену, склейка concat с `-c copy`.

Правила: `window.renderAt(t)` — чистая функция времени (без requestAnimationFrame и `Math.random`), HUD обновляется там же; `NeutralToneMapping`; EffectComposer (HalfFloat RT, `samples: 4`) → RenderPass → UnrealBloom (порог 1.1) → OutputPass; тени `PCFShadowMap` (PCFSoft удалён), `shadow.radius = 5`; свет: key #FFD6AE 1.75, hemisphere #9FD3E0/#0E1320 0.5, rim #9CC2FF 1.7, `environmentIntensity` 0.3 (выше — пересвет кремового); материализация — MeshStandardMaterial с `emissive: white`, `emissiveMap = map`, emissiveIntensity 1 → 0.09 при свете 0 → 1. Перед полным рендером — ключевые кадры (`node render.mjs frames 1.2 5.0 9.5`) и просмотр.
