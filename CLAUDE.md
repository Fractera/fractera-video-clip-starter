# CLAUDE.md — как продолжать этот проект

Это стартер музыкального клипа FRACTERA, который делается по конвейеру «образец + бриф → новый клип в том же стиле». Ролик FRACTERA — первый полный прогон конвейера: мы одновременно делаем клип и шлифуем навыки, чтобы потом забрать их в конвейер (и, возможно, в элемент Fractera).

## В начале каждой сессии

1. Прочитай `JOURNAL.md` целиком: текущий шаг, решения, открытые вопросы, ожидающие правки навыков.
2. Прочитай `.claude/skills/reference-to-clip/SKILL.md` — это точка входа: шаги, файлы, контрольные точки.
3. Подключённые наборы правил (раздел навыка «Подключаемые наборы правил»): `.claude/skills/vizavi-motion` (качество движения), `fractera-lego-motion` (стиль проекта), `fractera-song` (песня). Если папка навыка содержит только README-заглушку — попроси у Романа сохранённую версию.
4. После каждого шага обнови `JOURNAL.md` (статус шага, решение, что дальше) и закоммить.

## Правила

- Стиль, а не клон. Из образца берём приёмы и пропорции; слова, мелодию, аранжировку, кадры, персонажей и логотипы образца в результат не переносим. Слова образца не храним — только смысл своими словами и тайминг.
- `reference/` и кадры образца в `library/` и `analysis/` — только для внутренней работы, не публиковать. Репозиторий должен оставаться приватным.
- История, слова и произношение — Романа: сохраняем дословно, предлагаем, он утверждает.
- Агент не слышит звук: о звуке судим по замерам (`tools/audio`), то, что слышно только ухом, спрашиваем у Романа.
- Общение с Романом — по-русски, коротко и прямо. Он не занимался видео и звуком раньше: объяснять без жаргона.

## Где что лежит

| Путь | Что |
| --- | --- |
| `JOURNAL.md` | состояние проекта, решения, открытые вопросы |
| `.claude/skills/` | навыки: reference-to-clip, vizavi-motion, fractera-song, fractera-lego-motion |
| `reference/` | образец: лёгкая копия клипа на шкале трека (`lgtm-reference-lowres.mp4`), мастер-трек `lgtm-track.mp3` |
| `library/raw/`, `library/ready/` | 58 блоков образца: клип, паспорт; в ready — с чертежом. Каталог — `library/README.md`, индекс — `library/blocks.json` |
| `analysis/` | замеры: карта песни, голоса, сетка, листы кадров 1 кадр/с |
| `tools/audio/` | отделение голоса, сетка и разделы, детектор бота, карта песни (README внутри) |
| `tools/blocks/` | нарезка блоков, лёгкая копия образца |
| `engine/` | 3D-движок рендера (Three.js + Playwright + ffmpeg) и пробный ролик |
| `docs/` | ссылки на живые документы в claude.ai (`links.md`) и их копии на 2026-11-07 |

Имена из навыка reference-to-clip → файлы этого прогона: `source/` → `reference/`; `song-map.json` → `analysis/song/structure.json` (сетка, такты, разделы, громкость) + `voice_map_final.json` (голоса); `style-bible.md` → пока раздел «Грамматика стиля» в `docs/library-rev13.md`; `song-spec.md` → `docs/track-spec-rev14.txt` и навык fractera-song.

## Окружение

ffmpeg; Python 3 с `librosa soundfile onnxruntime scikit-learn matplotlib`; Node 20+ и Playwright с настоящим Chrome (на сервере без GPU — SwiftShader, ≈ 0.9 с на кадр 1080p на 2 ядрах). Модель отделения голоса скачивается командой из `tools/audio/README.md` и в git не хранится.
