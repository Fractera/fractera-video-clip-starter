# tools/blocks — нарезка блоков и лёгкая копия образца

Запускались один раз на исходных записях экрана (174 и 116 МБ). В репозитории исходников нет: результат уже лежит в `library/` и `reference/`. Пути в скриптах — от рабочей папки первой сессии; для повтора поправить пути в начале файлов.

| Файл | Что делает |
| --- | --- |
| `cut_blocks.py` | режет 58 блоков из записей: от начала блока − 1 с до конца + 1 с (в пределах записи), 1280 px, 30 к/с, H.264 crf 23, звук — мастер-трек (AAC 96k), чтобы звучал чистый трек, а не запись; кладёт паспорта и пишет `library/blocks.json` |
| `lowres.filter` | фильтр ffmpeg для `reference/lgtm-reference-lowres.mp4`: обе записи на чёрной подложке 640×404, 15 к/с, на своих местах шкалы трека; в пропусках плашка «нет записи — только звук»; таймкод трека в углу |

Границы блоков и сдвиги записей — `tools/audio/blocks.py` и `analysis/song/alignment.json` (запись 1 начинается на 11.061 с трека, запись 2 — на 202.216 с).
